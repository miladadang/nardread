# нарды

Длинные нарды против бота. Один HTML-файл, без сборки и зависимостей, рассчитан на экран телефона.

- три уровня бота: легко, средне, сложно
- правила: одна фишка с головы за ход, запрет блока из шести подряд, выброс из дома, марс
- открыть: `index.html` в браузере, либо включить GitHub Pages (Settings → Pages → ветка main)
